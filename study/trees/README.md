* Is a non linear data structure with hierachial rlships btwn its elements without having any cycle.  It is basiically  reversed from a real life tree.

Tree terminology:

1. Root - top node without parent.
2. Edge - link btwn parent and child.
3. Leaf - node which does not have children.
4. Sibling - children of same parent.
5. Ancestor - parent etc. of a node.
6. Depth of a node - length of the path from root to node.
7. Height of node - length of path from node to the deepest node.
8. Depth of tree - depth of tree node.
9. Height of tree - height of root node.
